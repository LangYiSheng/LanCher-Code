# 交互与命令

使用 `uv run lancher` 启动。首次配置依次填写供应商连接、模型并确认；取消不保存，返回上一步保留输入。

## 阶段与权限

新会话默认进入执行。输入区可以选择「讨论 → 计划 → 执行」，`Shift+Tab` 只切阶段，不发送草稿、不改变权限策略。

| 阶段 | 可用操作 |
|---|---|
| 讨论 | 读取、查找、搜索项目文件，读写当前 Session 工作目录，以及明确声明 `readOnlyHint=true` 的 MCP 工具 |
| 计划 | 同上，另外可以使用计划工具保存当前 Session 的 `workspace/plan.md` |
| 执行 | 现有工具按权限规则与策略运行 |

讨论和计划都不开放通用 Shell、普通源码写入或未声明只读的 MCP；当前 Session 的 `workspace/` 文件读写已批准。MCP 的只读属性由服务器声明，路径批准也不构成操作系统沙箱。阶段限制先于允许规则与跳过询问策略。

权限是独立选项：标准（`default`）、自动编辑（`acceptEdits`）、跳过询问（`bypass`）。进入只读阶段不会丢失已选策略，回到执行后继续使用它；路径限制、危险命令黑名单和现有规则继续生效。运行、等待审批、压缩上下文时不能切阶段、权限或模型。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/discuss [任务]` | 进入讨论；带参数才提交任务 |
| `/plan [任务]` | 进入计划；带参数才提交任务 |
| `/do [任务]` | 进入执行；带参数才提交任务 |
| `/permissions [default\|acceptEdits\|bypass]` | 查看或修改权限策略，不改变阶段 |
| `/model [供应商ID/模型ID]` | 选择本次模型，不改变新对话默认 |
| `/session <new\|list\|resume\|rename\|archive\|remove> [UUID] [标题]` | 新建、列出、恢复、改标题、归档或删除项目会话 |
| `/session stop` | 停止本轮及当前 Session 全部托管进程，记录、草稿和队列保留 |
| `/tasks [list\|show\|read\|stop\|background] [进程UUID]` | 查看当前会话的进程列表与详情、输出、输入，或停止与转后台 |
| `/compact` | 压缩当前上下文；进度与结果显示为聊天中的折叠活动行 |
| `/settings theme <dark\|light>` | 保存并立即切换主题 |
| `/settings thinking <on\|off>` | 显示或隐藏思考，不影响工具记录 |
| `/settings busy-enter <follow_up\|steer\|draft>` | 设置忙时 Enter 为排队、补充或保留草稿 |
| `/settings default-model <供应商ID/模型ID>` | 保存新对话默认模型，不改变本次选择 |
| `/settings open` | 打开完整设置，编辑连接、模型参数、MCP 与权限规则 |
| `/status` | 展开或收起 HUD 状态详情 |
| `/exit` | 退出程序 |

命令菜单使用「加粗命令名　中文用途 · 简短解释」。一级只显示命令，精确输入 `/session`、`/model`、`/permissions`、`/settings` 后显示下一层；子命令、模型、审批策略和设置值均在输入区逐级选择，不必打开其他面板。支持英文前缀和中文用途检索；选中项下方显示影响范围与当前按键行为。命令在所有工作阶段均可发现，执行时仍遵守忙闲限制。旧 `/mode` 已移除，未知命令保留草稿并报错，不发送给模型。

方向键选择，Tab 或 Enter 填入，再按 Enter 执行；Esc 关闭菜单并保留输入。Session 与进程补全填入完整 UUID，Session 候选同时显示标题，改标题参数保留空格。`/session resume` 可按 UUID 前缀或标题查找，选择后仍填入完整 UUID。窄屏标题提示只占一行并裁短，完整 UUID 保留；长标题可通过 `/session list` 阅读。参数错误、持久化或切换失败均保留输入。菜单限制高度，窄终端优先显示命令名与中文用途，通过方向键滚动访问所有项。忙时仍可使用 `/tasks` 和 `/session stop`；其他命令保留草稿等本轮结束，不会作为普通消息排队。

首条消息自动创建 Session，`/session new` 刷新旧对话并打开新草稿；下一条消息才创建新 UUID。`resume <UUID>` 按完整 32 位 UUID hex 恢复，`rename <UUID> <标题>` 修改标题，标题允许空格和重复。列表显示短 ID，命令不接受短 ID。旧 `save` 与 `--force` 已移除。归档、删除先显示标题和完整 UUID 并确认；取消保留草稿，确认前当前 Session 发生变化则拒绝旧操作。当前会话请先 `new` 再归档或删除。

项目会话位于 `./.lancher/sessions/<UUID>/`，保存阶段、权限、本次模型、计划和待处理输入。待处理消息恢复为暂停，不自动执行，未完成的工具操作也不重放。事件、列表缓存与 checkpoint 格式版本为 `2`；旧格式和旧 `.lancher/session/` 文件原样保留、不迁移。列表单独报告不支持或损坏的会话，恢复旧格式时提示新建会话。完整说明见 [Session 生命周期](workflows/session-lifecycle.md)。

## 安静对话与 HUD

正文连续显示，工具活动默认折叠；失败与等待批准保持可见。工具记录不受思考显示开关影响。上滚阅读时，新消息不会强制拉到底部。

上下文压缩也显示为聊天中的活动行：运行时图标转动，结束后原地显示成功、失败或已停止。点击标题，或聚焦后按 Enter / Space，可查看前后 token 估算、上下文减少比例、耗时及原因。手动、自动、超限后压缩共用此交互，记录随 `/session resume` 恢复；上次未完整结束的活动显示已中断。详见 [聊天中的压缩记录](workflows/context-compaction.md)。

HUD 分别显示本次模型、阶段、权限、预计上下文和任务状态。预计上下文是下一次请求的估算占比；累计输入、缓存输入、输出及 MCP 服务器状态位于详情，不能把累计用量当作上下文占用。

新消息被成功接收（包括忙时排队或补充）后自动收起 HUD 状态详情；空输入、保留草稿、命令报错不会将其收起。思考与工具详情遵循各自的折叠规则，不受此操作影响。

默认深色，设置的界面偏好可切浅色。模型选择器分别标记「本次使用」「新对话默认」，同名模型显示供应商和 API 名辅助区分。

## 忙时输入

工作时输入框可继续编辑，Enter 默认排到下一轮。设置可改成补充当前任务或仅保留草稿。只有运行层接受消息后，输入框才会清空。

- **排到下一轮**：当前任务成功结束后依次处理。待处理项可编辑、移除、转成补充，不覆盖新的输入草稿。
- **补充当前任务**：当前响应或已启动工具组完成后生效，后续未启动工具跳过。补充以用户消息加入；已发生的操作不会回滚。
- **审批中补充**：旧的未执行审批被撤销，不创建允许规则；过期面板点击无效。
- **停止或失败**：队列暂停，草稿和未消费消息保留；明确继续后才处理。任务结束后迟到的补充也保留为暂停项。

`Shift+Enter` 换行；`Ctrl+C` 在工作或审批中停止本轮，手动压缩时取消本次操作。空闲时第一次按下显示退出提示，3 秒内再按一次才退出；超时或继续输入、点击操作会撤下确认。停止工作的那次按键不累计到退出确认；收尾期间重复按键只提示正在停止。主输入区 Esc 同样停止本轮，会话后台继续运行；命令菜单中 Esc 关闭菜单，审批面板中拒绝该次审批，弹窗中返回。

退出会完成托管进程、Session 写入者和连接的收尾，然后在普通终端打印告别、可复制的完整恢复命令与本次启动已上报用量。新建空白草稿后退出，会提示本次最近实际使用且仍存在的对话；仅启动后直接退出，不从旧历史随便选一段对话。用量覆盖本次跨对话、跨模型、压缩及中断请求，缓存命中属于输入，不重复计入总量；缺失统计显示未知，缓存比不完整或数据异常时显示 `--`。详情将会话累计消耗与当前上下文估算分开显示。完整解释见 [结束工作与恢复对话](workflows/app-exit.md) 和 [Token 与上下文](workflows/token-accounting.md)。

## 进程任务窗口

`/tasks` 或 `/tasks list` 打开当前 Session 的进程列表。选中行并回车查看详情，日志每隔短时间按独立游标刷新；模型读取日志不会把界面输出读掉。输入栏发送一行内容，保留前后空格并在末尾加换行；这是真实进程 stdin，可能触发程序行为，不是聊天消息。用户实际点击发送属于直接操作，模型发起的输入仍要经过工具权限判断。

「转后台」把本轮进程明确交给 Session；随后停止本轮、切换对话，它继续运行。「停止进程」收尾该进程及托管子进程；「停止会话」覆盖本轮和会话后台。返回窗口只关闭观察视图，不停止进程。完整说明见 [工具执行](workflows/tool-execution.md)。

跨应用退出的后台任务尚不支持，退出会统一收尾。重启仅恢复记录和日志，无法重连的活动记录显示失联，不自动执行旧命令。

状态栏显示当前 Session 的后台进程和未读完成通知数量，通知旁提示 `/tasks`。按下停止本轮后，后台数量仍在，表示这些进程继续由会话管理。查看通知本身不会请求模型；下一条正常用户消息才携带待处理完成摘要。

## 计划确认与权限提示

计划成功保存且本轮完成后，显示当前会话的计划正文及「按此计划开始执行」。该动作校验所展示版本，冻结正文并真正提交执行请求；工具仍遵守当前权限策略。新一轮规划使旧版本暂不可执行，失败和取消不会启用过期按钮。磁盘上已有的计划文件不会自动成为获准计划。

审批展示实际命令或文件差异、工作目录和用途。主操作为「仅允许本次」「拒绝本次」；重复命令的会话／项目范围在次级选项中展示，默认精确匹配完整命令。已有通配规则保留原语义，拒绝一次操作不必结束整个任务。

审批焦点下，`D` 展开完整请求，`M` 查看可选授权范围，`I` 或 `Ctrl+I` 回到草稿；小终端使用紧凑审批行，详情和差异在可滚动视图中阅读。聊天状态详情通过 `/status` 或“详情”按钮打开，不再绑定 `Ctrl+D`。

## 设置保存

设置首页按供应商组织模型，分别管理连接、模型覆盖、本次选择和新对话默认。每个条目保存后回到父目录；放弃只影响当前草稿，不撤销此前已经保存的条目。

保存模型不会改写 MCP 或权限文件。模型从下一次请求使用新值；MCP 修改需重启。若配置已保存但本次模型热更新失败，界面分别报告两个结果并保留原运行时。密钥、环境变量引用、继承值和稳定 ID 不因界面改版而改变。
