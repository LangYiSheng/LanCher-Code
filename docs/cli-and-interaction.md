# 交互与命令

使用 `uv run lancher` 启动。首次配置依次填写供应商连接、模型并确认；取消不保存，返回上一步保留输入。

## 阶段与权限

新会话默认进入执行。输入区可以选择「讨论 → 计划 → 执行」，`Shift+Tab` 只切阶段，不发送草稿、不改变权限策略。

| 阶段 | 可用操作 |
|---|---|
| 讨论 | 读取、查找、搜索项目文件，以及已配置且明确声明 `readOnlyHint=true` 的 MCP 工具 |
| 计划 | 同上，另外可以保存指定计划文件 |
| 执行 | 现有工具按权限规则与策略运行 |

讨论和计划都不开放通用 Shell、普通文件写入或未声明只读的 MCP。MCP 的只读属性由服务器声明，并非本地隔离保证。阶段限制先于允许规则与跳过询问策略。

权限是独立选项：标准（`default`）、自动编辑（`acceptEdits`）、跳过询问（`bypass`）。进入只读阶段不会丢失已选策略，回到执行后继续使用它；路径限制、危险命令黑名单和现有规则继续生效。运行、等待审批、压缩上下文时不能切阶段、权限或模型。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/discuss [任务]` | 进入讨论；带参数才提交任务 |
| `/plan [任务]` | 进入计划；带参数才提交任务 |
| `/do [任务]` | 进入执行；带参数才提交任务 |
| `/permissions [default\|acceptEdits\|bypass]` | 查看或修改权限策略，不改变阶段 |
| `/mode <default\|plan\|acceptEdits\|bypass>` | 旧命令兼容入口；plan 只切阶段，其余只改权限 |
| `/model [供应商ID/模型ID]` | 选择本次模型，不改变新对话默认 |
| `/session <list\|save\|remove\|rename\|resume> [名称]` | 列出、保存、删除、改名或恢复项目会话 |
| `/compact` | 压缩当前上下文 |
| `/settings` | 打开设置目录 |
| `/exit` | 退出程序 |

命令菜单先展示中文用途，再展示命令和影响范围。方向键选择，Tab 或 Enter 填入，再按 Enter 执行；Esc 关闭菜单。模型与会话参数仍可补全。忙时命令保留在草稿中，等待本轮结束后执行，不会作为普通消息排队。

`/session save <名称>` 绑定保存文件；`resume <名称> --force` 明确放弃当前未保存会话。项目会话位于 `./.lancher/session/`，恢复阶段、权限、本次模型和计划快照。待处理消息恢复为暂停，不自动执行。

## 安静对话与 HUD

正文连续显示，工具活动默认折叠；失败与等待批准保持可见。工具记录不受思考显示开关影响。上滚阅读时，新消息不会强制拉到底部。

HUD 分别显示本次模型、阶段、权限、预计上下文和任务状态。预计上下文是下一次请求的估算占比；累计输入、缓存输入、输出及 MCP 服务器状态位于详情，不能把累计用量当作上下文占用。

默认深色，设置的界面偏好可切浅色。模型选择器分别标记「本次使用」「新对话默认」，同名模型显示供应商和 API 名辅助区分。

## 忙时输入

工作时输入框可继续编辑，Enter 默认排到下一轮。设置可改成补充当前任务或仅保留草稿。只有运行层接受消息后，输入框才会清空。

- **排到下一轮**：当前任务成功结束后依次处理。待处理项可编辑、移除、转成补充，不覆盖新的输入草稿。
- **补充当前任务**：当前响应或已启动工具组完成后生效，后续未启动工具跳过。补充以用户消息加入；已发生的操作不会回滚。
- **审批中补充**：旧的未执行审批被撤销，不创建允许规则；过期面板点击无效。
- **停止或失败**：队列暂停，草稿和未消费消息保留；明确继续后才处理。任务结束后迟到的补充也保留为暂停项。

`Shift+Enter` 换行；`Ctrl+C` 在工作或审批中停止任务，空闲时退出。Esc 只处理当前焦点层：关闭菜单或拒绝该次审批。

## 计划确认与权限提示

计划成功保存且本轮完成后，显示当前会话的计划正文及「按此计划开始执行」。该动作校验所展示版本，冻结正文并真正提交执行请求；工具仍遵守当前权限策略。新一轮规划使旧版本暂不可执行，失败和取消不会启用过期按钮。磁盘上已有的计划文件不会自动成为获准计划。

审批展示实际命令或文件差异、工作目录和用途。主操作为「仅允许本次」「拒绝本次」；重复命令的会话／项目范围在次级选项中展示，默认精确匹配完整命令。已有通配规则保留原语义，拒绝一次操作不必结束整个任务。

审批焦点下，`D` 展开完整请求，`M` 查看可选授权范围，`I` 或 `Ctrl+I` 回到草稿；小终端使用紧凑审批行，详情和差异在可滚动视图中阅读。`Ctrl+D` 打开／收起聊天状态详情。

## 设置保存

设置首页按供应商组织模型，分别管理连接、模型覆盖、本次选择和新对话默认。每个条目保存后回到父目录；放弃只影响当前草稿，不撤销此前已经保存的条目。

保存模型不会改写 MCP 或权限文件。模型从下一次请求使用新值；MCP 修改需重启。若配置已保存但本次模型热更新失败，界面分别报告两个结果并保留原运行时。密钥、环境变量引用、继承值和稳定 ID 不因界面改版而改变。
